# 문서

코드가 아닌 문서는 모두 여기에 둡니다. 루트와 `app/`·`components/` 안에
흩어져 있던 것을 모았습니다.

| 위치 | 담는 것 |
|---|---|
| `specs/` | 서비스 정의 문서 — 개발기획서, 운영자 가이드, 약관·개인정보처리방침·가정통신문 |
| `plans/` | 지난 계획 문서 — 업그레이드 계획 v1~v4, UI 개선 계획, 기능별 PRD |

루트에 남겨 둔 문서는 두 개입니다.

- `CLAUDE.md` — 작업 지침. 도구가 루트에서 찾습니다.
- `design.md` — 디자인 스펙. `CLAUDE.md`가 상대 경로로 참조합니다.
